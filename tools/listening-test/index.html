Blind listening test

Works offline. Audio never leaves this computer. You will hear a reference recording of a speaker (their real voice, different words) and four clips in random order. One clip may be the unprocessed original; you are not told which.

1. Setup

Choose the session folder (listening-test-…). Only reference_original.wav and sample_1.wav … sample_4.wav are used; the KEY file is ignored and never read.

Reference (the speaker's real voice)

Which clip do you think is the unprocessed original voice?

Send the CSV to the experimenter. Answer every question to enable the button.
